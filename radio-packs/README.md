# Паки радио

Содержимое этой папки нужно разместить в корне репозитория
`DOHC/dohcdesk-releases` в его основной ветке. Приложение читает
`https://raw.githubusercontent.com/DOHC/dohcdesk-releases/HEAD/radio-packs/index.json`.
Новые паки появляются после нажатия «Обновить», без выпуска нового APK.
Для первой установки поддержки паков требуется обновлённое приложение.

В магнитоле: «Регионы и станции» → «Загрузить данные радио» → выбрать пак →
«Загрузить». Интернет нужен для списка и скачивания; установленный пак работает
офлайн. Установка заменяет весь каталог и избранное. Ошибка скачивания или проверки
не меняет текущий каталог. Файлы хранятся в закрытой папке приложения, root не нужен.
Ручной импорт JSON и выбор папки логотипов остаются доступны.

## Первый пак

`moscow-kirzhach/` — исходный набор: 2 региона, 13 станций, 11 логотипов.
`moscow-kirzhach-v1.zip` — готовый архив для загрузки.

## Добавление пака

1. Создайте папку с `fm.json` (формат `version: 1`, как в первом паке) и
   `logos/`. Поле `logo` станции — имя файла без пути; допустимо пустое значение.
2. Упакуйте содержимое папки в ZIP: в корне архива должен быть `fm.json`,
   изображения — в `logos/`. Дополнительная внешняя папка не допускается.
3. Добавьте запись в `index.json`: уникальный `id`, `name`, `description`,
   имя ZIP в `file`, SHA-256 архива в `sha256` (64 строчные шестнадцатеричные цифры).
   Пример расчёта: `shasum -a 256 radio-packs/moscow-kirzhach-v1.zip`.
4. Опубликуйте архив и обновлённый индекс вместе. При обновлении существующего
   пака используйте новое имя архива, например `moscow-kirzhach-v2.zip`.

Ограничения: ZIP до 32 МиБ, распакованные файлы суммарно до 64 МиБ,
JSON до 2 МиБ, изображение до 4 МиБ и 4096×4096 пикселей. Имена паков,
архивов и логотипов: латинские буквы, цифры, точки, дефисы, подчёркивания;
первый символ — буква или цифра, длина до 120 символов.
